# Changelog

L'historique des versions de LarappeUI est maintenu à la racine du dépôt, dans un seul
fichier pour éviter deux journaux divergents :

➡️ **[CHANGELOG.md](../CHANGELOG.md)**

Le format suit [Keep a Changelog](https://keepachangelog.com/) et le versionnage
respecte [SemVer](https://semver.org/lang/fr/).

Les modifications en cours de développement sont regroupées sous la section
`[Unreleased]`, à compléter dans la même PR que le changement.
